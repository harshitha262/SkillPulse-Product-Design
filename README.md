# 🎓 SkillPulse – AI-Powered Student Productivity Platform

AI-powered student productivity platform designed using **Figma**, **Design Thinking**, **UI/UX Design**, **Wireframing**, and **Interactive Prototyping**.

---

## 📖 Overview

SkillPulse is an all-in-one productivity platform that helps students improve learning consistency, focus, and academic performance through AI-powered tools and an intuitive user experience.

---

## 🎯 Problem Statement

Students often struggle with:

- Maintaining study consistency
- Managing academic tasks
- Staying focused
- Tracking progress
- Organizing study resources

SkillPulse addresses these challenges by combining productivity tools with AI-powered assistance in a single platform.

---

## ✨ Features

- User Authentication
- Goal Tracking
- Flashcards
- Pomodoro Timer
- AI Journal

- Mood Tracking
